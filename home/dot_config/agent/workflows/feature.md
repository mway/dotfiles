# Feature Implementation Workflow

## Phase 1: Understand Requirements

1. Read feature request carefully
2. Identify all requirements (stated and implied)
3. Note constraints
4. Ask clarifying questions if needed
5. Create TODO list for implementation

## Phase 2: Plan Implementation

1. Break down into atomic tasks
2. Identify dependencies between tasks
3. Find opportunities for parallel work
4. Design high-level approach
5. Get user approval on approach

## Phase 3: Implement

1. Follow the plan systematically
2. Write tests as you implement (or before)
3. Update TODO progress continuously
4. Mark tasks complete immediately
5. Spawn subagents for parallel work

## Phase 4: Test

1. Run unit tests
2. Verify all tests pass
3. Check test coverage (aim for 80%+)
4. Test edge cases manually if needed

## Phase 5: Quality Check

1. Run linter
2. Fix any issues
3. Format code
4. Verify no regressions

## Phase 6: Document

1. Update relevant documentation
2. Add code comments for non-obvious logic
3. Update CHANGELOG if applicable

## Phase 7: Review

1. Self-review changes
2. Verify requirements met
3. Check for potential issues
4. Present to user for feedback
